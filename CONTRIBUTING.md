# Contributing to the Enterprise Spring Portfolio

We welcome contributions! This repository features **67** production-grade Kotlin/Spring services.

## Contribution Rules
1. **Coroutines**: Use Kotlin Coroutines and Virtual Threads.
2. **Hexagonal Architecture**: Maintain strict separation of layers.
3. **No Python**: This is a Kotlin-only ecosystem. Do not add Python scripts.
4. **Star the Repo**: Help us grow by starring this repository!

## How to Submit
- Fork the repository.
- Create a feature branch.
- Submit a PR with your feature or fix.
- Ensure the project passes `./gradlew build`.
